# Bicho Ambiental

Web de bichoambiental.com, publicada con GitHub Pages.

- `index.html`: toda la web (textos, estilos y animaciones en un solo archivo).
- `compartir.jpg`: imagen que aparece cuando se comparte el link en WhatsApp, LinkedIn o Instagram.
- `robots.txt` y `sitemap.xml`: para Google.
- `404.html`: página para direcciones que no existen.

Para cambiar algo: abrir `index.html`, tocar el lápiz (Edit), cambiar y guardar con "Commit changes". En 1 a 3 minutos se ve en la web.
